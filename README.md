# Этикетки + коды «Честный знак»

Программа вставляет коды маркировки «Честного знака» в потребительские этикетки чая и одновременно
готовит второй экземпляр кода (для защитной плёнки / внешней упаковки) с тем же номером.

Работает прямо в браузере, без установки и без интернета. Файлы никуда не отправляются — всё
обрабатывается на вашем компьютере.

## Как запустить

1. Скачайте репозиторий (зелёная кнопка **Code → Download ZIP**) и распакуйте.
2. Откройте файл `index.html` двойным щелчком (лучше в Chrome, Яндекс.Браузере или Edge).

Товары, шаблоны и история кодов хранятся в этом браузере. Кнопка **«Резервная копия»** сохраняет всё в
один файл; **«Восстановить»** загружает его обратно (например, на другом компьютере).

## Что получается на выходе

Загружаете шаблон этикетки и PDF с кодами из «Честного знака» (например, 500 страниц), получаете три файла:

| Файл | Что внутри |
|---|---|
| `…_этикетки.pdf` | 500 этикеток 75×120 мм. На каждой свой код DataMatrix с текстом под ним в красной зоне, а в синей зоне `артикул дата НОМЕР` |
| `…_коды.pdf` | Исходный файл кодов (500 стр.), на каждой странице добавлено то же `артикул дата НОМЕР`. Это для наклейки на защитный слой |
| `…_журнал.csv` | Таблица «номер ↔ код маркировки» для сверки и архива (открывается в Excel) |

Правило соответствия жёсткое: **страница N файла кодов → этикетка N → номер (начальный + N − 1)**.
Порядок не меняется, страницы не пропускаются и не повторяются. Код вставляется в этикетку как вектор
(без потери качества), поэтому сканируется так же, как исходный.

Пример: начальный номер 501, файл на 250 кодов → номера 501–750. На этикетке
`shu50 251126 501`, номер напечатан крупнее и другим цветом. На странице кода для внешней упаковки
стоит то же самое, так что фасовщик клеит пару с одинаковым номером.

## Работа по шагам

1. **Товар.** Введите артикул (латиницей, например `shu50`) или выберите его из списка. Сохранённые товары
   подсказываются по первым буквам. Для каждого товара запоминаются шаблон, положение зон и последний номер.
2. **Шаблон этикетки.** Лучше всего **PDF** точного размера 75×120 мм: текст будет чётким при любом масштабе.
   PNG/JPG тоже подойдут, но не меньше 300 dpi (для 75×120 мм это около 886×1417 пикселей). Если разрешение
   мало, программа предупредит.
3. **Зоны.** Координаты в миллиметрах от левого верхнего угла. По умолчанию они уже совпадают с вашим
   макетом (красная зона 23×23,5 мм справа вверху, синяя над ней). Справа виден предпросмотр с рамками зон.
   В готовые файлы рамки не попадают.
4. **Партия.** Выберите дату фасовки в календаре (на этикетке она печатается как `ДДММГГ`, например 251126),
   начальный номер и файл кодов. Программа сама посчитает страницы и покажет диапазон номеров.
5. **Сформировать.** Появятся ссылки на три файла. Последний номер запоминается, и следующая партия этого
   товара предложит начать со следующего.

## Защита от ошибок

- Одинаковые коды внутри одного файла: формирование **блокируется**.
- Коды, которые уже печатались раньше: предупреждение с номером и датой прошлой печати (повторная печать
  разрешена после подтверждения).
- Если на какой-то странице не найден DataMatrix, программа покажет номера страниц.
- После изменения файла кодов его нужно загрузить заново, иначе формирование не запустится.

## Технически

- `index.html`, `style.css`, `app.js`: интерфейс; данные хранятся в IndexedDB браузера.
- `core.js`: разбор PDF «Честного знака» (поиск DataMatrix и текста кода) и сборка PDF. Работает и в Node.
- `lib/pdf-lib.min.js`: библиотека [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17.1 (MIT).
- Проверка на реальном файле: `npm install && node tests/verify.js коды.pdf шаблон.pdf 1`. Скрипт собирает
  файлы и перечитывает их, сверяя код и номер на каждой странице.

Ограничение: артикул и дата печатаются стандартным шрифтом Helvetica Bold, поэтому кириллица в артикуле
автоматически переводится в латиницу.
