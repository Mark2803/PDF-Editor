# Этикетки + коды «Честный знак»

Программа делает три вещи:

1. **Вставляет коды маркировки** из PDF «Честного знака» в потребительские этикетки чая. DataMatrix
   получается максимально крупным, под ним идёт текст кода, рядом артикул, дата фасовки и сквозной номер.
2. **Готовит второй экземпляр кода** для защитной плёнки (внешней упаковки) с тем же номером, чтобы
   фасовщик клеил пару без ошибок.
3. **Проверяет коды в «Честном знаке»** перед отправкой на маркетплейс: введены ли они в оборот, не выбыли
   ли, существуют ли вообще.

Всё работает на вашем компьютере, файлы никуда не загружаются. Наружу уходят только сами коды,
и только при проверке в «Честном знаке».

## Как запустить

### Вариант 1. Полный (с проверкой кодов). Рекомендуется

1. Один раз установите **Node.js** (бесплатно): https://nodejs.org → кнопка LTS → обычная установка.
2. Скачайте эту папку (зелёная кнопка **Code → Download ZIP**) и распакуйте.
3. Дважды щёлкните **`start.bat`** (на Mac: `start.command`). Откроется браузер со страницей
   `http://localhost:8787`. Чёрное окно не закрывайте, пока работаете.

### Вариант 2. Только этикетки (без проверки)

Откройте `index.html` двойным щелчком. Этикетки и коды формируются, но проверка в ЧЗ из файла не
заработает: браузер не пускает такие запросы.

Товары, шаблоны и история хранятся в браузере. **«Резервная копия»** сохраняет всё в один файл,
**«Восстановить»** загружает его обратно (например, на другом компьютере). Учтите, что вариант 1
(`localhost:8787`) и вариант 2 (файл) для браузера — разные места хранения.

## Вкладка «Этикетки»

1. **Товар и партия.** Артикул латиницей (`shu50`, подсказки по первым буквам), дата фасовки (печатается
   как `ДДММГГ`) и начальный номер. Для товара запоминаются шаблон, раскладка и последний номер.
2. **Файлы.** Потребительская этикетка (лучше PDF точно 75×120 мм; PNG/JPG от 300 dpi) и PDF кодов из
   «Честного знака» — перетаскиванием или выбором. При загрузке программа читает **каждый DataMatrix** и
   сверяет его с текстом под ним.
3. **Настройки раскладки** (свёрнуты внизу, обычно не нужны):
   - *Код максимально крупно* (по умолчанию): DataMatrix ≈ 31 мм занимает всё свободное место справа
     от рисунка, а артикул, дата и номер стоят в левом верхнем углу.
   - *Как на макете*: номер над кодом, DataMatrix ≈ 25 мм.
   - *Свои координаты*: любые мм от левого верхнего угла.

   «Текст под кодом, %» задаёт размер строки кода относительно квадрата (по умолчанию 70%). Весь текст
   чёрный, номер крупнее и жирнее.
   Там же размер бумажки кода для внешней упаковки (20×30 мм) и запас от края (1,5 мм).
4. **Сформировать.** На выходе три файла: этикетки, коды для внешней упаковки и журнал CSV «номер ↔ код».

Соответствие жёсткое: **страница N файла кодов → этикетка N → номер (начальный + N − 1)**.

## Вкладка «Проверка кодов в ЧЗ»

На вход: PDF из «Честного знака», Excel (`.xlsx`), CSV или TXT (по коду в строке), можно несколько
файлов сразу или вставить список. С вкладки «Этикетки» коды текущей партии отправляются на проверку
кнопкой «Проверить эти коды в Честном знаке».

| Результат | Что значит | Можно отправлять? |
|---|---|---|
| **Годен** | В обороте | да |
| **НЕ годен** | Не введён в оборот (эмитирован/нанесён), выбыл, продан, списан, заблокирован или не найден | **нет** |
| **Внимание** | Код найден, но статус необычный или не прошла проверка подписи | проверьте вручную |
| **Не проверен** | Нет связи / сервер не ответил | нажмите «Повторить с ошибками связи» |

Проблемные коды показываются первыми, полный отчёт скачивается в CSV. Если коды партии проверены и
среди них есть негодные, программа предупредит об этом перед формированием этикеток.

### Как устроена проверка и её ограничения

- Используется **тот же открытый сервис, что и у приложения «Честный знак» для покупателей**
  (`mobile.api.crpt.ru`): без входа в личный кабинет, без ЭЦП и токенов.
- Для проверки нужен **полный код** вместе с криптохвостом (`…<GS>91…<GS>92…`). В тексте под квадратом
  его нет, поэтому программа читает сам DataMatrix из PDF (векторный, без камеры) и проверяет
  контрольную сумму.
- Сервис **отвечает только с российских IP-адресов**. С VPN или из-за границы будет ошибка 451.
- Это **недокументированный** сервис мобильного приложения: «Честный знак» может его изменить. Если
  ответы станут непонятными, в отчёте CSV есть столбец «Ответ сервера» для диагностики.
- Запросы идут по 2 параллельно с паузой 300 мс (500 кодов ≈ 2–3 минуты). При ответе «слишком много
  запросов» программа сама делает паузу 20 секунд. Ускорять не советую: сервис может временно
  заблокировать адрес.
- Официальный путь для бизнеса — True API «Честного знака» с авторизацией по ЭЦП. Его можно подключить
  позже, если открытого сервиса окажется недостаточно.

### Программа-посредник (`server.js`)

Браузер не разрешает странице напрямую обращаться к чужому серверу, поэтому `start.bat` запускает
маленькую программу (`server.js`, без дополнительных библиотек). Она открывает приложение и пересылает
**только** запросы проверки кода в ЧЗ. Её можно запустить и на своём сервере в России
(`HOST=0.0.0.0 PORT=8787 node server.js`, лучше за HTTPS и с паролем на уровне веб-сервера), а в
приложении указать адрес в «Настройках подключения».

## На сайте: раздел «Менеджмент» (tea-master-team.ru)

Адрес: `https://tea-master-team.ru/management/labels/`. Открывается только из админки: «Менеджмент» → PIN →
карточка «Этикетки и Честный знак» (ссылка с токеном `#t=…`). Токен проверяется по таблице
`management_access_tokens` базы сайта, после чего инструмент выдаёт свою сессию на 12 часов (не дольше токена).
Без неё страница показывает «Доступ закрыт», а проверка кодов не работает.

Устройство как у «Воронки продаж WB»: Node без библиотек и сборки, служба `labels` на `127.0.0.1:3400`,
папка `/home/ivanc1539/pdf-editor`, nginx-файл `nginx.ssl.conf_labels` (префикс `/management/labels/` nginx убирает).

### Установка (один раз, под root в свежем SSH-терминале)

Папку создаёт root: пользователь `ivanc1539` не может сам создавать папки в `/home/ivanc1539`.

1. Код и настройки:
   ```
   U="runuser -u ivanc1539 --"
   mkdir -p /home/ivanc1539/pdf-editor && chown ivanc1539: /home/ivanc1539/pdf-editor && cd /home/ivanc1539/pdf-editor
   $U git clone https://github.com/Mark2803/PDF-Editor.git .
   $U cp .env.example .env
   DB="$(grep -E '^DATABASE_URL=' /home/ivanc1539/tea-market-v2/backend/.env | cut -d= -f2- | tr -d '"')"
   SS="$($U node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))")"
   printf 'DATABASE_URL=%s\nSESSION_SECRET=%s\n' "$DB" "$SS" >> .env
   chmod 600 .env && ss -ltnp | grep 3400
   ```
   Последняя команда ничего не выводит — порт 3400 свободен.
2. Служба:
   ```
   cp deploy/labels.service /etc/systemd/system/ && systemctl daemon-reload && systemctl enable --now labels
   sleep 2 && systemctl is-active labels && curl -s http://127.0.0.1:3400/api/me
   ```
   Ответ `{"authRequired":true,"authenticated":false}` — работает.
3. Адрес в nginx:
   ```
   cp deploy/nginx-labels.conf /home/ivanc1539/conf/web/tea-master-team.ru/nginx.ssl.conf_labels
   nginx -t && systemctl reload nginx
   ```
4. Карточка в админке появляется после выкладки backend сайта (TeaMarketV2, ветка `рефакторинг`, шаги 1–2 его инструкции).

### Обновление

```
cd /home/ivanc1539/pdf-editor && runuser -u ivanc1539 -- git pull && systemctl restart labels
```
Откат: `runuser -u ivanc1539 -- git checkout -f ПРЕЖНИЙ_КОММИТ && systemctl restart labels`.
Журнал: `journalctl -u labels -n 50`.

Данные (товары, шаблоны, история кодов) хранятся в браузере того, кто работает, а не на сервере —
«Резервная копия» в шапке сохраняет их в файл.

## Файлы

- `index.html`, `style.css`, `app.js`: интерфейс (данные хранятся в IndexedDB браузера).
- `core.js`: разбор PDF «Честного знака» и сборка PDF.
- `datamatrix.js`: чтение DataMatrix ECC200 из векторного PDF с проверкой Рида–Соломона.
- `checker.js`: чтение кодов из PDF/XLSX/CSV, запросы в ЧЗ, разбор статусов.
- `server.js`, `start.bat`, `start.command`: программа-посредник и запуск; `deploy/`: служба и nginx для сайта; `.env.example`: настройки для сайта.
- `lib/pdf-lib.min.js`: [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17.1 (MIT).
- `tests/verify.js`: `npm install && node tests/verify.js коды.pdf шаблон.pdf 1` читает все
  DataMatrix, собирает файлы и сверяет код и номер на каждой странице.
- `tests/mock-crpt.js`: имитация сервиса ЧЗ для проверки без интернета.
